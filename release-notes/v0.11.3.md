# Answer42 v0.11.3

## Изменения
- **Удалённые базы в браузерном режиме.** `start_session(client_mode="browser", browser_test_server="host[:порт]")` (или `ONEC_MCP_BROWSER_TEST_SERVER`) указывает сервер, на котором веб-клиент регистрируется для тестирования: менеджер кластера (порт по умолчанию 1541) или веб-сервер файловой базы (1538). Менеджер тестирования подключается к нему по TCP, поэтому сервер должен быть доступен с этой машины (например, по VPN или tailscale; за nginx с открытыми 80/443 это не работает).
- Без параметра для не-локальной публикации сопряжение не запускается: ответ `connected: false` с причиной и подсказкой, DOM-инструменты (`html_*`, `browser_*`) работают.
- Версия протокола менеджера `2026.11.16.1`: `MCPTestManager.cf` пересобирается автоматически из исходников.

## Совместимость
- Локальные публикации и режим `thin` не изменились.
- Содержимое HTML-полей (фреймов) инструментами `html_*` в браузерном режиме пока не читается.

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: удалённая база через tailscale (менеджер кластера, порт 1541): сопряжение, `windows_list`, `open_navigation_link`, `form_state`. Не проверялось: `table_rows` на удалённой базе, порт 1538, Edge, IIS, Linux.
