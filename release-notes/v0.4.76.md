# Answer42 v0.4.76

## Improvements
- Accelerate `ui_tree(include_rag_types=true)` for summary-RAG snapshots by scoping form-element lookup to the active metadata object instead of building a global form index.
- Add scoped `lookup_form_element_types(..., object_full_name=...)` support for both configuration-summary RAG and the local SQLite RAG store.
- Improve RAG enrichment for filtered/flat `ui_tree` results by deriving the active metadata object from navigation URLs, active-form diagnostics, and serialized form names.
- Enrich flat `objects` results as well as nested `children` trees.
- Improve matching for form element names, titles, dotted data paths, active form names, and auto-generated form hints.
- Change `ui_tree(include_rag_types)` default from `false` to `"auto"`: RAG enrichment now turns on automatically for `diagnostic`, `data`, and `full` profiles while keeping the default `navigation` profile fast and compact.
