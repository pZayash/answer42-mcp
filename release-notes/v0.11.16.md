# Answer42 v0.11.16

## Изменения
- **`table_set_field` с коротким именем колонки.** Раньше для колонки «Дт» значение вводилось верно, но ответ был «значение не подтвердилось»: проверка читала первую колонку, в названии которой есть «Дт» («Субконто2 Дт»). Теперь значение читается из колонки найденного редактора.
- **`table_copy_row` и `table_delete_row` в пустой таблице.** Копирование отвечало `copied: true`, хотя строки нет, а удаление — «not_supported» с текстом про неподходящее состояние. Оба вызова возвращают `false` с причиной `no_current_row` и понятным текстом.
- **`set_field_value` с многострочным текстом.** 1С показывает перевод строки в поле как «¶», и ввод текста с переводами строк считался неудавшимся. Переводы строк при сравнении больше не учитываются.
- **`tabular_document_save` без `format`.** Если `format` не задан, формат берётся из расширения `path` (`report.xlsx` даёт xlsx), иначе pdf. Раньше файл `.xlsx` без `format` получал содержимое PDF.

## Совместимость
- Новых инструментов нет. У `tabular_document_save` значение `format` по умолчанию теперь пустое (раньше `pdf`): при явном `format` ничего не меняется, без него и без известного расширения результат прежний (pdf).
- Изменён модуль менеджера (`MCPTestManager.cf` пересобирается автоматически из исходников).

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: тестовая база Бухгалтерии, проводки бухгалтерской операции (`Дт`, субконто), табличная часть «Реализации товаров» (добавление, выбор номенклатуры, количество, цена, копирование, перемещение, удаление, пустая таблица), форма нового контрагента (перечисление, ИНН, страна, многострочный комментарий), отчёт с периодом, список номенклатуры (поиск, ячейки, настройки списка).
