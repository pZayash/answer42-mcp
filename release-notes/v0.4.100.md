# Answer42 v0.4.100

## Changes

- Добавлен requests-only runtime probe для web-публикаций 1С: до запуска Xvfb, test manager и test client он выполняет штатную временную авторизацию и читает `e1cib/misc?cmd=startInfo`.
- Probe определяет фактически опубликованные версию платформы, название и версию конфигурации, а также подключённые расширения. Эти данные сразу заполняют контекст сессии и cache для RAG и hints.
- Временный web-сеанс 1С теперь явно завершается после probe через browser-compatible `e1cib/logout`, чтобы не ожидать server-side idle timeout.
- Если web-публикация однозначно отклоняет переданные учётные данные, `start_session` возвращает понятную ошибку авторизации до запуска локальной 1С-инфраструктуры. Неподдерживаемые или временно недоступные публикации остаются best-effort fallback-сценарием.
- Добавлена CLI-обёртка `scripts/read_webclient_start_info.py` для безопасного requests-only чтения runtime metadata.
