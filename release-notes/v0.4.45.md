# Answer42 v0.4.45

## Fixed

- Fixed the platform fast path used by `find_object` / `search_objects`: empty `name` or `title` search parameters are now passed to 1C `НайтиОбъект()` / `НайтиОбъекты()` as `Неопределено` instead of an empty string.
- This restores platform `НайтиОбъекты()` discovery for queries such as `search_objects(name="Товары")`, `search_objects(type="Тестируемая таблица")`, and command/list-form object searches where one of the optional parameters is omitted.

## Verified

- Live checked on `https://base.42clouds.com/bp/186690/`, form `Документ.ПоступлениеТоваровУслуг.Форма.ФормаДокументаОбщая`: `search_objects(name="Товары")` and `search_objects(name="Товары", type="Тестируемая таблица формы")` return `method="fast_platform_search_objects"`, `fast_found=true`.
