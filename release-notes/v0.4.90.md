# Answer42 v0.4.90

## Fixes

- Fixed `metadata_objects_from_catalog` cache refresh semantics: the in-memory metadata snapshot now reads the full saved Universal report, independent of the public `limit` argument.
- Kept `limit` only as a compatibility/reporting parameter; use `max_results` to limit how many matched objects are returned to the agent.
- This prevents small calls such as `limit=500` from poisoning the per-session cache with a truncated metadata snapshot.
