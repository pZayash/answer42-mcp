# Answer42 v0.5.8

## Changes
- Ошибки инструментов больше не сводятся к «Error executing tool X»: текст исключения (диагностика 1С, логи ibsrv, ErrorWindow) возвращается вызывающему.
- `start_session` для файловой базы: FATAL ibsrv (например, исключительная блокировка базы) сообщается сразу, с логом и подсказкой, вместо ожидания по таймауту; лог ibsrv в cp866 читается корректно. При ошибке старта в ответ добавляется ЖР менеджера тестирования.
- Если файловая база уже открыта другим процессом, `start_session` подключает клиент тестирования напрямую через `/F`; причина — в `test_client.connection_fallback`.
- Очистка после неудачного старта и `stop_session` не ждут зависший менеджер; общий ibsrv освобождается, а не убивается.
- На Windows при выборе свободного порта учитываются порты, занятые на 127.0.0.1.
- Скриншот на скрытом рабочем столе больше не «замораживает» тест-клиент (после PrintWindow окно получает SWP_FRAMECHANGED) и включает отдельные окна форм, открытых без владельца.
- MCPTestManager: фильтры по заголовку в `wait_form`, `wait_object`, `activate_window` и др. снова работают — локальные переменные с именами свойств формы (Заголовок, ТолькоПросмотр, …) объявлены через `Перем`.
- `activate_window` ищет окно и по заголовку формы, для заблокированного окна возвращает `window_unavailable`; при старте недоступное из-за модальной формы окно не активизируется.
- Удалён инструмент `export_eventlog`.
- Синтаксический контроль MCPTestManager конфигуратором (`/CheckModules`) выполняется в тестах и на Windows.
- Включает изменения v0.5.6 и v0.5.7.
