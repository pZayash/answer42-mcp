# Answer42 v0.4.43

Search performance and type lookup fixes for 1C test-client UI objects.

## Changed

- `search_objects` now tries the platform `НайтиОбъекты()` fast path for exact name/type searches before falling back to the existing DFS traversal.
- `find_object` can now attempt its platform fast path for type-only queries instead of immediately falling back to DFS.
- Shared test-object type conversion now accepts spaced/caption-style type names such as `Тестируемая таблица формы` by mapping them to platform type names like `ТестируемаяТаблицаФормы`.

## Fixed

- Relaxed manager-side type matching to align with Python post-filtering, so broader type strings such as `Тестируемая таблица` can match `Тестируемая таблица формы` during DFS fallback.
