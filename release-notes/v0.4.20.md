# Answer42 v0.4.20

Patch release after live validation of v0.4.19 UI search filtering.

## Fixed

- Added a manager-side serialized-result post-filter for `search_objects` to prevent unrelated rows from leaking when title/type filters are applied in some 1C runtime contexts.
- Avoided using `Объект` as a loop variable in the new BSL post-filter because it conflicts with form data context and can raise `Нельзя изменять поле, содержащее объект данных формы`.

## Validation

- Live smoke on a 1C test session verified `search_objects(title="Закрыть", type="Тестируемая кнопка формы", limit=10)` now returns only `КомандаЗакрыть` instead of unrelated news buttons.
