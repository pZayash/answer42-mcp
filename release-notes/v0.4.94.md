# Answer42 v0.4.94

## Changed

- Reworked bundled Answer42 skills to keep concise operational guidance instead of duplicating MCP tool descriptions.
- Made packaged skill assets under `src/mcp_1c/assets/skills/*` the only canonical skill source in the repository and removed duplicate `skills/*` copies.
- Updated installation docs to describe packaged skill assets and the default `answer42 install-skills` behavior.

## Form hints

- Clarified recommended hint scopes in bundled skills:
  - `base` for data, settings, rights, functional options and report/user variants of a concrete infobase;
  - `configuration` for reusable principles of a concrete configuration, without configuration version;
  - `extension` for behavior introduced by an extension;
  - `global` for common managed UI / standard 1C interface patterns.
- Removed configuration version from form-hints API and matching mechanics. Configuration version remains available as session/configuration diagnostic metadata, but hints are now keyed and matched by configuration name only.
