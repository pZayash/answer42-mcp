## Исправления сохранения табличных документов

- `tabular_document_save` теперь распознаёт результат отчёта, который test-client показывает как обычное `ТестируемоеПолеФормы` с представлением данных `ТабличныйДокумент`.
- Для PDF используется `ЗаписатьСодержимоеВФайл(<СохранитьКак>)` через очередь результата файлового диалога, с проверкой обоих вариантов `СохранитьКак`.
- Из-за несовпадения индексов фильтров test-client API с интерактивным порядком диалога PDF выбирается по сигнатуре файла `%PDF`, затем копируется в запрошенный `path`.
- В результат tool добавлено поле `selected` с фактическими `filter_index`, `save_as` и `copied_to`.
- В packaged wheel обновлён `MCPTestManager.cf`.

## Тесты

- Проверено локально: сборка `MCPTestManager.cf`, `py_compile`, `pytest`, `ruff`, `python -m build`, `twine check`.
- Проверено в живой 1С BP: отчёт `Остки товаров` сохранён как настоящий `%PDF-1.7`.
- В CI выполняются `pytest`, `ruff`, сборка пакета и `twine check`.
