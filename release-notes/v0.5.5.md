# Answer42 v0.5.5

## Fixes
- Fixed `start_session` failing on Windows for web publications with a bare "Error executing tool start_session". The pre-start web runtime probe used `ZoneInfo("Europe/Moscow")`, which on Windows requires the `tzdata` package; installations without it (for example `uv tool install answer42`) failed before any 1C process was started.
- `tzdata` is now a declared dependency on Windows, and the probe falls back to a fixed UTC+3 offset when no time-zone database is available.

## Verification
- Full unit suite, Ruff, Python compilation, package build, Twine metadata check, and `git diff --check` passed before the release commit. Two Windows-only test failures (`fcntl` import under a simulated Linux platform, `.exe` suffix in a fake platform path) already fail on v0.5.4 and are unrelated to this change; GitLab CI runs on Linux.
- Live check on Windows with 1C 8.5.1.1343 against a 42Clouds web publication: the web runtime probe succeeds in an environment without `tzdata`, and `start_session` connects the test client.
