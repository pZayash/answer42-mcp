# v0.4.54

Patch release for slow 1C managed-form UI actions.

- Raised the default `watchdog_timeout` for `click_button` from 20 to 120 seconds so slow managed-form openings are not reported as blocked too early.
- Raised the default `watchdog_timeout` for `ui_tree_resource_action(action="click_button")` from 20 to 120 seconds.
- Raised the default `watchdog_timeout` for `tabular_document_save` from 20 to 120 seconds to tolerate slow thin-client file dialogs and large tabular documents.
- Updated bundled Answer42 skill guidance: a `dangerous_action_watchdog_timeout` should be treated as an inspect/retry signal, not proof that 1C hung.
