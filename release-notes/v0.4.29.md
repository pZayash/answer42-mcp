- Keep dynamic-list sort direction changes inside the `Настройка списка` form by setting the `Направление сортировки` table column through the table-editor path; no post-close/list-level order fallback is used.
- Remove the public `dynamic_list_filter_by_current_value` MCP tool; use text-based dynamic-list search/settings tools instead.
- Add regression coverage for the table-editor settings flow, removed quick/filter context tool, display-text choice-list handling, and absence of `list_order` fallback in `dynamic_list_set_settings`.
