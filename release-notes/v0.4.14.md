# Answer42 v0.4.14

Patch release for user-facing 1C validation diagnostics.

## Fixed

- Added non-empty bridge error fallback so failed 1C bridge commands no longer surface as blank `Error executing tool ...` messages.
- Added post-step `client_diagnostics` to manager exception responses, including user-facing messages when a 1C UI command fails.
- Collected 1C user messages from the active tested client window and exposed both structured `user_messages` and `user_message_texts` in diagnostics.
- Cleared/closed the user-message panel after collecting messages to avoid stale diagnostics in later tool calls.
- Added lightweight current-element validation tooltip capture for inline validation messages without recursively scanning the full UI tree.
- Rebuilt bundled `MCPTestManager.cf` and `MCPTestClient.cf` assets.
