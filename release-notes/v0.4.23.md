# Answer42 v0.4.23

Corrective testing release after v0.4.22.

## Changed

- Replaced a brittle regression test that prohibited a specific BSL method name with a real 1C syntax validation test.
- Added `test_manager_cf_passes_1c_configurator_syntax_check`: when 1C platform tools are available, pytest builds `MCPTestManager.cf` from `src/cf`, loads it into a temporary file infobase, applies the configuration, and runs `1cv8 DESIGNER /CheckModules -ThinClient -Server`.
- The syntax test skips automatically when `ibcmd`/`1cv8` are not available, so regular Python-only CI remains portable.

## Validation

- Local `tests/test_protocol.py` executed the real 1C configurator syntax check and passed with `Синтаксических ошибок не обнаружено!`.
- Full pytest passed.
- Ruff passed.
- Package build and twine check passed.
