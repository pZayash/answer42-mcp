# Answer42 v0.4.44

Fixes `search_objects` discovery of managed-form tabular sections that are available through the 1C test-client table API but are skipped by the generic object search path.

## Fixed

- `search_objects` now falls back to recursive table discovery when the generic DFS/platform search returns no matches, allowing form tables such as `Товары` in `Документ.ПоступлениеТоваровУслуг.Форма.ФормаДокументаОбщая` to be returned as `Тестируемая таблица формы`.
- Manager-side type filtering now accepts compatible normalized type names, so broad queries such as `Тестируемая таблица` match concrete table objects of type `Тестируемая таблица формы`.
