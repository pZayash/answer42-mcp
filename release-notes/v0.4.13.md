# Answer42 v0.4.13

Patch release for Answer42 UI traversal performance and dynamic-list settings stability after v0.4.12.

## Fixed

- Removed the unacceptable `skipped` path from dynamic-list settings E2E-critical flows.
- Fixed `dynamic_list_set_settings` ordering by selecting fields from `Доступные поля` and pressing `Выбрать` instead of typing into a choice-field settings column.
- Fixed `clear_first` for already-open list settings by closing settings, clearing the source list settings, and reopening settings.

## Performance

- Optimized scoped button search with platform fast-paths (`НайтиОбъект` / `ПолучитьОбъект`) and a per-search cache for expensive 1C test-client calls.
- Optimized `ui_tree` serialization with a per-call cache for properties, methods, children and command panels.
- Reduced duplicate `ui_tree` traversal by serializing inactive `pages` entries shallowly while keeping `current_page` fully expanded.
- Removed `ui_tree` node/depth limit API and BSL truncation logic entirely; `ui_tree` now traverses the full tree without `max_nodes` / `max_depth` parameters.
- Kept `include_data=false` as an optional performance switch for expensive data-presentation reads; it is not a tree-size limit.

## Tests

- Full local suite passed before release:
  - CF builds for MCPTestManager and MCPTestClient.
  - `py_compile`.
  - unit tests: `86 passed`.
  - `ruff check`.
  - full `E2E_PARALLEL=1 ONEC_MCP_REQUEST_TIMEOUT=240 scripts/e2e_stable.py`: smoke, dynamic-tables, dynamic-lists, dynamic-reports, coverage.
