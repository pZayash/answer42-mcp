## Changes
- Add `choose_current_row(expected_text=...)` to reliably position and verify selection-list rows before choosing them.
- Improve table cell editing for document tabular sections by preserving edit mode for reference-field fallbacks and reporting aggregate row-setting failures correctly.
- Extend `table_set_field` with optional `row` positioning so a single call can find a table/tree row and set a field in it.
- Support row checkbox controls such as `ДеревоКлассификатораПометка` without entering table edit mode; this enables loading OKEI classifier rows through the universal table field tool.
- Clarify checkbox off-path handling: `value=True` uses `УстановитьОтметку()`, while `value=False` attempts `СнятьОтметку()` and reports a clear unsupported-action error when the platform/control does not provide it.
