# Answer42 v0.11.10

## Изменения
- **Лишние формы выбора после `table_set_field`.** Ввод в ячейку таблицы (например, «Счёт Кт» в проводке) мог открыть одну-две формы выбора, которые регистрировались в тест-клиенте с задержкой и ломали ввод ошибкой «Недоступный пользователю элемент управления». Теперь менеджер ждёт появления окон, закрывает лишние формы выбора и один раз повторяет ввод. В ответе появляется `closed_stray_selection_forms`.
- **`close_form` с двумя одинаковыми окнами.** Если заголовок и имя формы у двух окон совпадают, закрытие первого не замечалось, и ответ был `closed: false` при закрытой форме. Теперь сравнивается число окон: ответ `closed: true`, `reason: closed_window_count_decreased`.
- **`open_navigation_link` по несуществующей ссылке.** Окно ошибки с единственной кнопкой «ОК» больше не остаётся поверх формы: менеджер нажимает её до того, как вернуть ошибку.
- **PDF записи прогона, страница «Ход проверки».** Таблица шагов разбивается на несколько листов («лист 2 из 6») вместо обрезки всего, что не влезло. Длинные подписи шагов обрезаются многоточием. Шаги таблиц, динамических списков, выбора типа, `field_info` и табличных документов получили русские названия вместо английских имён инструментов.

## Совместимость
- Новых инструментов и параметров нет, прежние вызовы работают как раньше.
- Изменён модуль менеджера (`MCPTestManager.cf` пересобирается автоматически из исходников).

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: тестовая база Бухгалтерии, ввод пяти полей проводки без лишних окон, повторный `close_form` на двух одинаковых окнах, неверная навигационная ссылка, запись прогона из 59 шагов в PDF с проверкой всех листов.
- Не проверялось: составные поля со строкой, числом или датой, настоящие деревья значений, Linux.

## Не менялось
- `<...>` в ячейках субконто: это штатный текст 1С для ещё не заданного значения.
- Уровень, признак группы и «развёрнуто» в `table_rows`: в API тест-клиента для строки таких свойств нет.
