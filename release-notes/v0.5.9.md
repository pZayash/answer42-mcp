# Answer42 v0.5.9

## Changes
- StreamableHTTP: один сервер обслуживает всех клиентов, поэтому неявной сессии по умолчанию больше нет. `start_session` без `session_id` создаёт сессию с уникальным id и возвращает его; инструменты, которым нужна сессия, без явного `session_id` возвращают понятную ошибку. В stdio поведение не меняется.
- Порты сессии: если вся полоса недоступна (например, попала в зарезервированный Windows диапазон `excludedportrange`), порт ищется дальше вместо ошибки «No free port found».

## Verification
- Локально на Windows (8.5.1.1343): pytest 317 passed, включая синтаксический контроль конфигуратором; ruff, py_compile, build, twine check.
- Вживую через StreamableHTTP: вызов без `session_id` отклоняется, `start_session` без id создаёт отдельную сессию, работа по возвращённому id.
- GitLab CI runs unit tests and package checks on branch and tag pipelines.
- PyPI publishing and GitLab Release creation are performed by the tag pipeline.
