# Answer42 v0.4.98

## Changes

- На Linux `start_session` теперь заранее проверяет наличие Xvfb и при его отсутствии возвращает понятную ошибку с командами установки для Debian/Ubuntu и Fedora/RHEL вместо `FileNotFoundError`.
- Документировано и закреплено поведение для desktop Linux: Answer42 всегда использует два собственных изолированных Xvfb-дисплея (manager и client), не подменяет их существующим `DISPLAY` и не захватывает пользовательский рабочий стол.
- `screenshot` больше не возвращает PNG как base64 в MCP tool result. В stdio возвращается сохранённый путь, размер и диагностика.
- В StreamableHTTP ответ `screenshot` содержит непрозрачную одноразовую URL-ссылку на PNG. Ссылка действует один час по умолчанию (`ONEC_MCP_SCREENSHOT_URL_TTL_SECONDS`), живёт только пока работает сервер и может быть опубликована через reverse proxy с `ONEC_MCP_SCREENSHOT_URL_BASE` / `--http-public-base-url`.
