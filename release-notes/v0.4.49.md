# Answer42 v0.4.49

## Changed

- Added 1C-side filtered flat traversal for `ui_tree(name=.../title=.../type=...)`, including `limit`, so filtered UI inspections no longer require serializing the whole tree on new managers.
- Added structured `metrics` to `ui_tree` responses with bridge/Python/format timing, payload byte estimate, and node/object counters when available.
- Deduplicated `command_panels="only"` results by stable node identity fields.
- Added strict validation for `profile`, `group_mode`, `command_panels`, and `format` arguments.
- Extended `group_mode` with `flatten_layout`, `exclude_empty`, and `pages_only` in addition to `include`, `flatten`, and `exclude`.

## Verification

- Unit/protocol coverage updated for 1C-side flat traversal, validation, metrics, command-panel deduplication, and extended group modes.
