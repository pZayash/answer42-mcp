# Answer42 v0.4.32

## Removed

- Removed the public `create_new_item` MCP tool and the corresponding bridge command.
  The old implementation tried to press the active form's `Создать` button, but then
  fell back to `Таблица.ДобавитьСтроку()` on the first table it could find. That
  fallback could silently change the action from "create a catalog/document item" to
  "add a row to an arbitrary form table".

## Changed

- Updated stable E2E scenarios to use the explicit `click_button(name="ФормаСоздать")`
  flow when they need the standard form command. Table row insertion remains covered
  by explicit table tools such as `table_add_row`.
- Fixed a mojibake replacement character in the packaged MCP manager BSL module.

## Verification

- Static checks ensure `create_new_item` is not registered as an MCP tool and the BSL
  dispatcher no longer exposes `СоздатьНовыйЭлемент`.
