# Answer42 v0.4.71

## Changes
- Fix `table_set_field(..., create_if_missing=True)` regression for reference fields in table parts, preserving row-positioning and checkbox support from v0.4.69.
- Narrow the table checkbox fast-path so ordinary reference fields such as `Товары.Номенклатура` are not misclassified as checkbox columns.
- Report opened creation forms explicitly after direct text input: if a `(создание)` window becomes active while `create_if_missing=True`, `set_field_value` now returns `creation_window_opened=true` and `set=false` instead of a false-positive `set=true`.
- Improve table checkbox handling by reusing the detected checkbox control, including diagnostics/fallbacks for controls where the 1C test-client refuses direct mark/click actions.
