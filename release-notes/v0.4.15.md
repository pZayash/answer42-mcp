# Answer42 v0.4.15

Patch release for 1C UI diagnostics and table-part editing stability.

## Fixed

- Treated a closed 1C user-message panel as the documented normal case `user_messages_panel_closed` instead of surfacing `ПолучитьТекстыСообщенийПользователю` as noisy diagnostics.
- Fixed table-part direct input so `table_set_field` / `table_set_row_values` do not enter values unless the parent table row is confirmed to be in edit mode via `ТекущийРежимРедактирование()`.
- Fixed table reference-cell input by selecting dropdown choices while the row editor is still active, using `table_editor.ВвестиТекст+ВыполнитьВыборИзСпискаВыбора`.
- Fixed `close_form` on modified forms: save/discard MessageBox no longer causes a blank tool error or bridge timeout; the tool returns structured `close_blocked_by_modal_dialog` diagnostics.
- Added MessageBox diagnostics for ordinary dialogs, including `modal_form_name`, `modal_text`, `modal_buttons`, and `modal_looks_like_dialog`.
- Improved form-object ranking for interactive actions so visible, available, non-readonly fields are preferred over hidden/readonly duplicates.
- Clarified `dynamic_list_find` semantics by adding `matched` and `match_reason`; successful search execution is no longer confused with a current-row match.
- Rebuilt bundled `MCPTestManager.cf` and `MCPTestClient.cf` assets.
