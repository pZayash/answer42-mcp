# Answer42 v0.4.97

## Changes

- Исправлена совместимость `MCPTestManager.cf` и `MCPTestClient.cf` с платформой 1С 8.3.27: в обоих XML-исходниках `CompatibilityMode` и `ConfigurationExtensionCompatibilityMode` установлены в `Version8_3_27`.
- Сборка CF импортирует XML в чистую файловую ИБ (`ibcmd infobase config import`) и сохраняет конфигурацию (`ibcmd config save`), поэтому артефакту не передаётся требование более новой платформы от ранее собранного CF.
- CI использует образ с 1С 8.3.27.2214 и перед упаковкой проверяет загрузку обоих сформированных CF через `ibcmd config load`.
- Добавлен unit-тест, запрещающий возврат compatibility mode `Version8_5_1` в XML тестовых конфигураций.

- Локально прошли unit tests, Ruff, `py_compile`, package build и `twine check`.
