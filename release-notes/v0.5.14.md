# Answer42 v0.5.14

## Changes
- Ложные «успехи» и «ошибки» инструментов, найденные прогонами бенчмарка на 1С:ERP 2.5:
  - `set_field_value`: раннее «значение уже установлено» только при точном совпадении (раньше «HARD-1» считалось совпадающим с «HARD-1 ИЗМЕНЕНО», и ввод пропускался); числа с разрядами (`1,000`) и даты со временем подтверждаются; выбор пункта списка, текст которого отличается от значения в поле, засчитывается (`verified_value`, `list_item_text`).
  - Смена заголовка той же формы без нового окна больше не считается открытием окна (универсальный отчет после выбора объекта).
  - `table_set_field` выбирает значение из списка в ячейках без ввода текста (например «Actions» в заказе клиента); если пункта нет, ошибка перечисляет доступные пункты.
  - `toggle_field` перечитывает значение и сообщает о висящем вопросе платформы (`pending_dialog`).
  - `click_button`: сначала точное совпадение; по заголовку — только целым словом («No» больше не нажимает «Notification»).
  - `choose_current_row` в иерархических формах выбора сообщает `entered_group`, если выбранная строка — группа.
  - `open_navigation_link`: отказ приложения не открывает лишний «Универсальный отчет».
  - Диагностика: устаревший `error_info` сбрасывается после закрытия окна ошибки; `modal_text` содержит только текст диалога; формы-вопросы конфигурации (`ОбщаяФорма.ВопросДаНетОтмена`) распознаются как диалоги.
  - `ui_tree_diff` соблюдает `limit`; `form_state.modified` учитывает «*» в заголовке окна.
- **Несовместимое изменение:** признак `creation_window_opened` в ответах `set_field_value` / `table_set_field` переименован в `window_opened` — окно может быть и вопросом, не только формой создания.
- Английский интерфейс 1С: к поиску по русским заголовкам добавлены английские, снятые с живого клиента 1С:ERP 2.5 на платформе 8.5 — настройки и сброс настроек списка (`dynamic_list_*`), расширенный поиск, вывод списка, настройка формы, вкладки и колонки настроек, направления сортировки, вид сравнения, режимы поиска, панели командного интерфейса, колонки «Версии подсистем» / «Версии расширений», универсальный отчет по идентификаторам объектов метаданных. Колонки отбора берутся по техническим именам.
- Креды: CLI `answer42 credentials add|list|remove` (пароль запрашивается интерактивно или читается из stdin и не попадает в аргументы; `--account` / `--token` для аккаунтов HTTP-режима); хранилище перечитывает файл, если тот изменился, — перезапуск сервера не нужен.
