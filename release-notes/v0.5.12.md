  - `table_begin_edit`/`table_end_edit`/`table_editing_state` → `table_edit(action)`;
  - `field_dropdown_items`/`field_dropdown_state` → `field_dropdown(open)`;
  - `group_current_page` → `group_state` (`current_page`);
  - `field_value_text`/`field_tooltip` → `field_info` (`data_text`, `tooltip`);
  - `credentials_titles` → `credentials_list`;
  - `command_bar` → `object_command_panel` без имени объекта;
  - `tabular_document_text` → `tabular_documents(name|title)`.
