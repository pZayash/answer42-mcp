# Answer42 v0.6.0

## Изменения
- **Живые веб-страницы в HTML-полях** — новая группа инструментов `html`: `html_pages`, `html_text`, `html_query`, `html_click`, `html_type`, `html_wait`, `html_eval`, `html_console`. Они читают и меняют DOM страниц, которые рисуются скриптами (чаты, SPA), чего не умеет API клиента тестирования. Мост включается в `start_session` по умолчанию (`html_agent=true`, отключается `html_agent=false`); группа `html` показывается клиенту сама после `start_session`. Платформа используется как установлена, без копий и патчей.
  - Windows: Answer42 открывает встроенный Web Inspector HTML-поля (Ctrl+Alt+Shift+F12, работает и на скрытом рабочем столе), фокусирует строку консоли и вводит однострочный мост, который подключается к локальному WebSocket по одноразовому токену. После перезагрузки страницы мост вводится заново. Инспектор остаётся встроенным в нижнюю часть формы; первое подключение занимает 15–25 секунд.
  - Linux: тест-клиент запускается с `WEBKIT_INSPECTOR_SERVER`, и Answer42 подключается к удалённому отладчику WebKitGTK напрямую — без окна инспектора и ввода с клавиатуры. Пустые скрытые страницы `about:blank` пропускаются.
  - `html_console` возвращает ошибки и предупреждения консоли страницы и находит скрипты, которые эта сборка WebKit не разбирает (например `?.` в Windows-клиенте 1С). На Linux сообщения собираются с загрузки страницы, на Windows — с момента подключения моста.
- **Статический HTML через API клиента тестирования** (группа `forms`): `html_field_content` (HTML и видимый текст поля), `html_field_click_link`, `html_field_input`.
- `runtime.start_test_client` принимает дополнительные переменные окружения тест-клиента (`extra_env`).
- **Сайт документации** на GitLab Pages переделан на Sphinx + Furo: главная страница, руководства из README и `docs/`, «Что нового» из release notes и отдельный раздел «Справочник API» — страница на каждую группу инструментов с описаниями, параметрами, типами и значениями по умолчанию, собранная из реестра MCP-инструментов. Документация и справочник — на русском; описания инструментов для MCP-клиентов остаются английскими, перевод для сайта — в `docs-site/api_ru.json` (тест проверяет, что переведён каждый инструмент и параметр). Extra `docs` в `pyproject.toml` ставит зависимости сборки.

## Проверка

- Вживую на чате «НейроСотрудник» (веб-публикация, 8.5.1.1343): все инструменты `html_*` на Windows-клиенте (скрытый рабочий стол) и на Linux-клиенте (Debian 13, WebKitGTK 2.36, Xvfb); `html_console` нашёл ошибку разбора `?.` и `ReferenceError` на Windows и `ReferenceError` на Linux, где `?.` поддерживается.
