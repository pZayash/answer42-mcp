# Answer42 v0.5.4

## Improvements
- Added a background mode for Windows: with `ONEC_MCP_WINDOWS_DESKTOP=hidden` the 1C test manager and test client run on hidden per-session desktops (`Answer42-<scope>-<session>-manager` / `-client`), the Windows counterpart of Linux Xvfb. No 1C windows appear on the user's desktop and focus is never stolen.
- `screenshot` captures windows on the hidden desktop via `PrintWindow`; auto-maximize of the test client works there as well.
- The default Windows behaviour (`current` desktop) is unchanged. The MCP server still has to run in an interactive user session.

## Verification
- Full unit suite and Ruff on Linux (Python 3.13), Windows unit suite, Python compilation, package build, Twine metadata check, and `git diff --check` passed before the release commit.
- Live smoke on Windows with 1C 8.5.1.1343: `start_session`, `active_window`, `screenshot`, `stop_session` in hidden mode with no 1C windows on the current desktop.
