# Answer42 v0.4.51

## Changed

- Removed the unintended `ui_tree(limit=...)` argument and all flat-output truncation introduced in `v0.4.50`; filtered and `command_panels="only"` outputs are now unbounded again.
- Added a 1C platform fast path for simple `ui_tree(name=...)` / `ui_tree(type=...)` flat queries, with fallback to full flat traversal for title/complex cases.
- Added `fields` / field-set profiles for `ui_tree`: `auto`, `minimal`, `navigation`, `diagnostic`, `data`, `full`, plus comma-separated custom field lists.
- Kept timing/payload `metrics`, command-panel deduplication, strict argument validation, and extended group modes from `v0.4.50`.

## Notes

- Supersedes `v0.4.50` for the `ui_tree` contract because `limit` was not requested and should not be part of this tool API.
