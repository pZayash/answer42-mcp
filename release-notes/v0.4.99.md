# Answer42 v0.4.99

## Changes

- Исправлено поведение Linux desktop: если процесс Answer42 унаследовал непустой `DISPLAY`, `start_session` использует эту живую X11-сессию для test manager и test client и не запускает Xvfb.
- Для headless-запуска без `DISPLAY` сохранён прежний режим с двумя собственными Xvfb-дисплеями. Если Xvfb отсутствует, до создания сессии возвращается понятная инструкция: установить Xvfb либо передать доступный `DISPLAY`.
- Обновлена документация для desktop service: помимо `DISPLAY`, сервису обычно требуется доступ к X server через `XAUTHORITY`.

## Verification

- Проверены выбор inherited `DISPLAY`, headless fallback на два Xvfb-дисплея и понятная ошибка при отсутствии Xvfb.
- Полный suite, Ruff, `py_compile`, package build и `twine check` выполнены перед выпуском.
