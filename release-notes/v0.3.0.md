# Answer42 v0.3.0

## Highlights
- Reworked dynamic-list MCP API after the tools audit: clearer naming, removed legacy duplicate tools, and split live UI operations from RAG/metadata helpers.
- Added live dynamic-list settings helpers: available fields, current settings reader, batch filter/order setter with optional cleanup, quick current-value filter, and modal find.
- Added RAG autoconfigure fallback dumps: when registered sources are missing or version-mismatched, Answer42 can dump the live configuration/extensions via Designer `/S` or `/F`, or build temporary infobases from `.cf`/`.cfe` files.
- Improved metadata lookup/navigation diagnostics: `metadata_objects_from_catalog` works on dev-area hierarchical lists, tries dynamic-list output first, and `open_navigation_link` now suggests likely metadata objects.
- Hardened MCPTestManager/1C form module after live dev-area checks.
