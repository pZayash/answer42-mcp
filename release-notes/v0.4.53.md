# v0.4.53

- Added `ui_tree(delivery="auto|inline|resource")`; `auto` is the default and switches large responses to resources by threshold. `resource`: large UI-tree results are saved as MCP resources and returned inline only as `resource_uri`, `snapshot_id`, summary, metrics and preview.
- Added saved-snapshot tools: `ui_tree_resource_search`, `ui_tree_resource_get_node`, `ui_tree_resource_children`, `ui_tree_diff`, and `ui_tree_resource_action`.
- Updated Answer42 skills/README with guidance on when to use inline vs resource delivery and how agents should inspect snapshots without loading the full tree into LLM context.
- `ui_tree` summaries now include `types_count.by_family` and `types_count.by_type` so agents can see counts of buttons, fields, tables, groups and exact 1C UI object types before drilling into the tree.
