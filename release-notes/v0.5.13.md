# Answer42 v0.5.13

## Changes
- Группы инструментов: клиент по умолчанию видит только `core` (36 инструментов, ~8,6k токенов вместо ~24,8k). Остальные группы (`forms`, `tables`, `lists`, `commands`, `ui_snapshots`, `metadata`, `rag`, `recording`, `credentials`) подключаются параметром адреса `?tools=`, профилем `--tool-profile` или на ходу инструментом `tool_groups` с уведомлением `tools/list_changed`.
  - Выбор запоминается за процессом (stdio), за `Mcp-Session-Id` (stateful HTTP) или за `?client=` / учётной записью токена (протокол MCP 2026-07-28, stateless HTTP).
  - RAG-инструменты видны только пока RAG активен.
  - `ui_tree`, сохранивший результат в ресурс, сам включает `ui_snapshots`.
  - `--tool-groups off` / `ONEC_MCP_TOOL_GROUPS=off` возвращает прежний статический список (профиль по умолчанию `full`).
- `--http-stateful` для StreamableHTTP.
- Автоочистка данных сессий: при остановке удаляются кэши автономного сервера (~640 МБ на сессию); раз в час удаляются неиспользуемые папки сессий старше `ONEC_MCP_SESSION_DATA_TTL_HOURS` (24 ч). Сборщик осиротевших сессий теперь работает и в HTTP-режиме.
- `dynamic_list_output` возвращает хронометраж только при `include_timings=true`.
