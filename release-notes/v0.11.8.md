# Answer42 v0.11.8

## Изменения
- **Быстрее табличные части документов.** Замер на реальной БП (ПТУ на 20 строк, три поля в строке): строка через `table_set_row_values` — 12,9 → 5,9 с, `table_set_field` — около 1 с на поле, всё заполнение 20 строк — 517 → 121 с.
  - Поиск поля флажка выполняется только для булевых значений (раньше 0,3–0,8 с на каждое поле).
  - После пересчёта суммы режим редактирования строки возвращается активацией ячейки и повторным `ИзменитьСтроку`, без 3–4 с перебора команд «Изменить» в контекстном меню.
  - Ячейка без выпадающего списка запоминается и тогда, когда редактирование завершилось сразу после ввода (числовые поля): 2-секундное ожидание списка пропускается.
  - В журнале поиска поля редактора одна короткая строка вместо 8–10 обращений к клиенту.
- **Быстрый поиск объектов по имени.** Точное имя ищется платформенным `НайтиОбъект()` вместо обхода всей формы; ожидания выпадающего списка и модального окна для полей без них сокращены и запоминаются.
- **Настройки динамического списка.** `dynamic_list_clear_settings`: 12–13 с → 3,5 с при первом вызове и 0,35 с далее. Перебор запасных имён кнопки сначала идёт только по кнопкам формы и не ждёт `ПолучитьОбъект()` после промашки; сработавшая кнопка запоминается для того же набора кандидатов. Запасные проходы (все типы кнопок, обход дерева) сохранены.
- Отчёт доказательной записи: явная часовая зона на обложке (замечание ruff DTZ006).

## Совместимость
- Протокол и формат ответов инструментов не менялись. Порядок установки полей внутри `table_set_row_values` по-прежнему не гарантирован; для строгого порядка вызывайте `table_set_field` по колонкам.
