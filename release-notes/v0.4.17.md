# Answer42 v0.4.17

Patch release for robust button-click diagnostics and timeout reporting.

## Fixed

- Converted bridge request timeouts into explicit non-empty `BridgeError` messages, so slow 1C calls no longer surface as blank tool errors.
- Increased default bridge request timeout from 60s to 180s and gave `click_button` a 300s default timeout via `ONEC_MCP_CLICK_BUTTON_TIMEOUT` / global-timeout multiplier.
- Added manager-side phase diagnostics for `click_button`: active-window lookup, button search, matched button, press phase, post-action window diagnostics and total time.
- Added search statistics for button lookup: fast-platform attempts/time/result, DFS fallback method, visited nodes, child arrays and checked buttons.
- Made technical form command names such as `ФормаПровести` exact-only before substring fallback, preventing accidental matches like `ФормаПровестиИЗакрыть`.
- Added timing/node-count logging for `ui_tree`, `find_object` and `search_objects` manager-side flows.
- Rebuilt bundled `MCPTestManager.cf` and `MCPTestClient.cf` assets.
