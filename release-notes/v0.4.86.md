# Answer42 v0.4.86

## Fixes

- Fixed Answer42 startup on Windows when the global orphan-session reaper probes stored PIDs.
  Windows no longer uses `os.kill(pid, 0)` for PID liveness checks; it now uses the native `OpenProcess`/`GetExitCodeProcess` API and treats unexpected `OSError` from POSIX probing as a dead PID instead of crashing startup.
