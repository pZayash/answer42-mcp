# Answer42 v0.4.93

Reusable form hints discovery and scope-aware hint matching.

## Changed

- `start_session` now reports compact startup hint discovery:
  - `global_hints` for global reusable hint operations;
  - `startup_hints` for global plus matching configuration/extension hint operations.
- `ui_tree` now attaches compact `form_hints` discovery for the active form without exposing hint bodies.
  Global hints are intentionally excluded from `ui_tree`; only current form/base plus matching configuration/extension hints are advertised.
- `form_hints_set` and `form_hints_get` now support reusable scopes:
  - `base`;
  - `configuration`;
  - `extension`;
  - `global`.
- `configuration_name_version_from_subsystems` now returns `configuration_hints` with available hint operation names for the detected configuration.
- `installed_extensions_from_catalog` now returns `extension_hints` with available hint operation names for detected extensions.
- Configuration detection is cached by session and by normalized base URL in a persistent cache (`ONEC_MCP_CONFIGURATION_CACHE`) so configuration hints can be shown immediately after new Answer42 session starts.
- Session diagnostics now expose detected configuration/extension hint context.
- Answer42 skill instructions now direct agents to use form hints proactively when fields/tables differ from expectations, validation reports required fields, or the UI path was wrong.
