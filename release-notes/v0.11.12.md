# Answer42 v0.11.12

## Изменения
- **Отбор по дате в `dynamic_list_set_settings`.** Дата вводится в колонку «Дата» строки отбора (в колонке «Значение» стоит только вариант «Произвольная дата»), раньше такой отбор не устанавливался. Первый ввод даты при необходимости повторяется. Промахи первых попыток при удачном итоге больше не попадают в `errors`.
- **Порядок в `dynamic_list_set_settings`.** При `clear_first` прежний порядок стандартных настроек убирается, и заданный `orders` действительно определяет сортировку (раньше он добавлялся после стандартной сортировки по дате и ничего не менял).
- **`clear_first` при открытых настройках с изменениями.** Вопрос «Настройки изменены. Сохранить изменения?» закрывается ответом «Нет», вместо ошибки «Ни одна кнопка не нажалась».
- **`tabular_document_save`.** Фильтры файлового диалога пробуются по одному до первого, давшего нужный формат, вместо перебора всех 30 за один вызов с ответом в десятки килобайт ошибок. Окно ошибки, которое оставляет фильтр формата, не поддерживаемого 1С (например, «Превышена допустимая ширина документа Word 2007»), закрывается, и оно больше не ломает следующие попытки. Фильтр, давший формат, запоминается: повторное сохранение того же формата идёт сразу к нему. Каталог результата создаётся, если его нет.

## Совместимость
- Новых инструментов и параметров нет, прежние вызовы работают как раньше. У параметра `exact_filter_only` изменено описание: он устарел, фильтры всегда пробуются по одному.
- Изменён модуль менеджера (`MCPTestManager.cf` пересобирается автоматически из исходников).

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: тестовая база Бухгалтерии, отборы по дате, числу, строке и ссылке в разных сочетаниях, порядок по убыванию суммы, сохранение списка в xlsx, pdf, html, txt, mxl и xls, отчёта «Оборотно-сальдовая ведомость» в xlsx и pdf.
- Не проверялось: Linux, сохранение очень больших отчётов.

## Не менялось
- Иерархические списки с отбором: `table_rows` показывает свёрнутые группы без признака группы, в API тест-клиента для строки такого свойства нет. Нужную строку находят `dynamic_list_find` и `choose_current_row`.
