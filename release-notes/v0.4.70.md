# Answer42 v0.4.70

## Changes
- Add reusable 1C form hints tools:
  - `form_hints_set` saves plain-text or JSON operator hints for a form/scenario.
  - `form_hints_get` retrieves saved hints for the active or explicitly specified form.
- Store form hints on the Answer42 Python/MCP side, outside user infobases, under the runtime data directory with file locking.
- Resolve hint context from the active session/form when `base_url`, `form_name`, or `form_title` are omitted.
- Support per-base hints and global cross-base hints with `use_global` / `include_global`.
- Return an `operations` summary from `form_hints_get`, so callers can discover known scenarios for the current form before requesting a specific operation.
