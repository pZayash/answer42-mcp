# Answer42 v0.11.4

## Изменения
- **HTML-поля в браузерном режиме.** Инструменты `html_*` теперь работают внутри фреймов страницы: `html_pages` перечисляет дочерние фреймы как страницы `browser1.f1`, `browser1.f2`, ..., а `html_text`, `html_query`, `html_click`, `html_type`, `html_eval` и остальные принимают такой id в параметре `page`.
- **Фреймы другого домена.** Chrome запускает их как отдельные цели DevTools; они подключаются как страницы со `"kind": "iframe"` (например, чат НейроСотрудника `https://baymax.efsol.pro/neuro1c/`) и выбираются по id или части адреса: `page="neuro1c"`. Страница по умолчанию остаётся основной.
- `html_console` для фрейма отдаёт консоль его страницы.

## Совместимость
- Вызовы без параметра `page` работают как раньше: выбирается основная страница клиента.

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: удалённая база `dev-area-06` через tailscale (Chrome): фрейм на странице (`srcdoc`) и чат НейроСотрудника в фрейме другого домена: чтение текста, список элементов, ввод и очистка поля. Отправка сообщений не проверялась.
