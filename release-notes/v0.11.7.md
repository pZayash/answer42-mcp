# Answer42 v0.11.7

## Изменения
- **Читаемый PDF доказательной записи.** Раньше каждый шаг был тёмным слайдом со скриншотом и сырым JSON параметров и ответа. Теперь отчёт состоит из обложки (заголовок, дата, число шагов, длительность, итог, база, пользователь, платформа, тип клиента), таблицы «Ход проверки» и страницы на каждый шаг: понятное название, скриншот окна 1С, что сделано, что получилось; ошибки выделены красным. Технические детали вызовов MCP (запрос и ответ) вынесены в приложение в конце, пароли по-прежнему скрыты.
- `recording_start(title=...)` задаёт заголовок на обложке (по умолчанию «Протокол проверки»); база, пользователь и платформа подставляются автоматически.
- Шаги без скриншота (например, обращения к базе знаний) показывают результат словами.
- Если для печати PDF нет браузера, остаётся `recording.html` с тем же отчётом: его можно распечатать из любого браузера.
- SVG-слайды и сборка PDF через ImageMagick удалены.

## Совместимость
- В `manifest.json` записи добавлены поля `title`, `meta`, у событий `time` и `failed`; поле `slide` у событий убрано, каталог `slides/` больше не создаётся.
- Для PDF по-прежнему нужен Chrome или Edge.

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: отчёт собран реальным Chrome на демо-данных (8 шагов, ошибка, шаг без снимка), страницы просмотрены.
- Не проверялось: запись настоящей сессии, Edge, Linux (шрифты), разбивка приложения на листы в готовом PDF.
