# Answer42 v0.4.42

## Changes
- Fix `set_field_value` for fields whose web-client dropdown opens but contains no relevant value: Answer42 now closes the dropdown, records diagnostics, avoids unsafe selection of a missing value, and preserves the fallback chain.
- Add BSL-only recovery for stale web-client editors after failed dropdown input: the field is restored to the presentation it had before editing, the dropdown is closed, focus is moved through the 1C test-client form API, and the field is refreshed recursively.
- Keep recovery inside the 1C test-client/BSL layer. No new X11 key presses or Python-side editor-reset hook are used for `set_field_value`.
- Rebuild the bundled `MCPTestManager.cf` with the updated BSL manager.
