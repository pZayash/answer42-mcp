# Answer42 v0.4.48

## Changed

- Added `ui_tree(parent_name=...)` to serialize a subtree rooted at a specific UI node by exact technical name.
- The 1C manager now resolves `parent_name` before tree serialization, so large forms can be inspected from a known group/table without serializing the whole active window.
- Python keeps a compatibility fallback for older managers and reports `parent_not_found` when the requested parent cannot be resolved.

## Verification

- Includes unit/protocol coverage for the new argument and BSL manager parameter forwarding.
