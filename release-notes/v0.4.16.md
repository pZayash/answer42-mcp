# Answer42 v0.4.16

Patch release for the v0.4.15 CI lint regression and report-settings table diagnostics.

## Fixed

- Fixed CI lint failure on Python 3.13 / latest Ruff by catching builtin `TimeoutError` instead of aliased `asyncio.TimeoutError` in the `close_form` fallback.
- Enriched poor/blank bridge errors for `table_add_row` and `table_begin_edit` with structured Python-side fallback diagnostics.
- Improved BSL diagnostics for table edit/add-row operations on report-settings tables: empty 1C exceptions are now reported as explicit no-text errors instead of surfacing as blank tool failures.
- Kept report-settings table operations honest: if `ИзменитьСтроку()` does not enter `ТекущийРежимРедактирование()`, `table_begin_edit` reports `edit_mode_not_confirmed` instead of pretending input is safe.
- Rebuilt bundled `MCPTestManager.cf` and `MCPTestClient.cf` assets.
