# Answer42 v0.4.47

## Changed

- Optimized `ui_tree` defaults for navigation: `include_data=false`, `include_rag_types=false`, and command panels are excluded unless requested by profile or argument.
- Added `ui_tree` profiles: `navigation`, `diagnostic`, `data`, `full`, and `command_panels`.
- Added explicit command-panel controls via `include_command_panels` and `command_panels=auto|include|exclude|only`.
- Added `ui_tree` filters by exact technical `name`, title substring, and object `type`; active filters return a flat `objects` list.
- Added `group_mode=include|flatten|exclude` to keep groups, lift their children, or remove group subtrees in tree output.
- Added readable `format=outline` and `format=yaml|yml` presentations while keeping JSON as the default structured response.
- Removed compact tree child truncation from the Python wrapper; `ui_tree` remains not depth-limited.

## Documentation

- Updated tool descriptions, bundled Answer42 skills, and architecture/README notes to recommend targeted data tools instead of casual `include_data=true`.

## Release note

`v0.4.46` was superseded before a GitLab release was created because CI lint caught import formatting in tests after the protected tag had already been pushed. `v0.4.47` contains the same `ui_tree` functionality with the CI formatting fix.
