# Answer42 v0.12.0

## Изменения
- **Новая группа инструментов `diagnostics`** (включается через `tool_groups`): диагностика клиента тестирования по справке платформы.
  - `performance_metrics`: накопленные клиентом показатели производительности (число вызовов, длительность, отправленные и принятые байты); параметр `clear` сбрасывает их после чтения.
  - `action_timeout`: чтение и установка максимального времени ожидания одного действия тест-клиента (без параметра возвращает текущее значение).
  - `user_action_log`: журнал действий пользователя платформы (`start`, `stop`, `pause`, `resume`, `abort`; `stop` возвращает XML-журнал). Действия самого тест-клиента платформа в журнал не пишет, он полезен при записи действий реального пользователя.

## Совместимость
- Существующие инструменты и параметры не менялись. Группа `diagnostics` по умолчанию выключена; профили `full` и `all` её включают.
- Изменён модуль менеджера (`MCPTestManager.cf` пересобирается автоматически из исходников).

## Проверка
- Локально на Windows: pytest, ruff, py_compile, `git diff --check`, сборка пакета и `twine check`.
- Вживую: тестовая база Бухгалтерии, чтение и сброс показателей, чтение и установка предела времени действия, запись и остановка журнала.
- Не проверялось: Linux, содержимое журнала при действиях живого пользователя.

## Не менялось
- Метод тестового клиента «ВыбратьСообщениеПользователю» (переход к полю по сообщению) не добавлен: сообщения забираются диагностикой сразу после действия, панель закрыта.
