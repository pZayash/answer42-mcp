# Answer42 v0.11.9

## Изменения
- **Поля составного типа.** Когда поле может быть строкой, числом или ссылкой разных видов, 1С сначала открывает диалог «Выбор типа данных». Новый инструмент `choose_value_type` и параметр `value_type` у `set_field_value`, `table_set_field`, `choose_field_from_list` и `table_choose_field_from_list` выбирают тип и доводят ввод до конца: форма выбора этого типа, затем значение. Без `value_type` ответ содержит `type_selection_required` и `available_types` вместо ложной ошибки про справочник, а диалог остаётся открытым для `choose_value_type`. Тип выбирается по номеру строки, а не по тексту, поэтому «Номенклатура» не путается с «Номенклатурная группа».
- **Иерархические справочники.** `choose_current_row` ищет значение внутри группы стандартным поиском по всему списку, если на показанном уровне его нет (`found_by_search: true`), вместо ошибки «Строка для выбора не найдена».
- **Курсор после чтения таблицы.** `table_rows` возвращает текущую строку на место и в таблицах, где `ПерейтиКСтроке` отказывается принимать описание строки (диалог «Выбор типа данных»): возврат по индексу. Раньше курсор оставался на последней строке, и ОК выбирал не тот тип без ошибки.
- **close_form** на форме с изменениями больше не сообщает `closed: true`, когда лишь открылся вопрос «Сохранить изменения?»: ответ `closed: false`, `reason: confirmation_required`, `confirmation_buttons`.
- **Снимок экрана на видимом рабочем столе Windows.** Если окно 1С не найдено, весь монитор больше не снимается сам (в кадр попадали другие приложения): ошибка, весь экран только при `window=false`. Штатная служба на скрытом рабочем столе не затронута.

## Совместимость
- Новые параметры необязательные, прежние вызовы работают как раньше.
- Изменён модуль менеджера (`MCPTestManager.cf` пересобирается автоматически из исходников).
- Список групп инструментов: `choose_value_type` входит в основную группу `core`.
