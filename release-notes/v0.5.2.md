# Answer42 v0.5.2

## Breaking changes
- Removed unused MCP tools `form_hints_get` and `form_hints_set` and their local JSON persistence.
- Removed related response fields: `start_session.global_hints`, `start_session.startup_hints`, `ui_tree.form_hints`, `configuration_name_version_from_subsystems.configuration_hints`, and `installed_extensions_from_catalog.extension_hints`.
- Removed `ONEC_MCP_FORM_HINTS_FILE` and `ONEC_MCP_FORM_HINTS_LOCK`. Existing `form-hints.json` files are no longer read; no migration is provided.

## Improvements
- Added the built-in MCP prompt `universal_report_workflow` with a complete safe workflow for the standard 1C Universal report.
- Kept `open_navigation_link` generic: Universal Report-specific guidance no longer appears in its tool description.

## Verification
- Full unit suite, Ruff, Python compilation, package build, Twine metadata check, and `git diff --check` passed before the release commit.
