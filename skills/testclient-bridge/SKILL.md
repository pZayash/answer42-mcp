# testclient-bridge

Используй этот скилл, когда задача связана с управлением интерфейсом 1С через MCP `testclient-bridge`: запуск менеджера тестирования, подключение тест-клиента, навигация по формам, выбор ссылочных полей, работа с таблицами/табличными частями, скриншоты и диагностика 1С.

## Когда применять

- Нужно выполнить действие в 1С UI на живом стенде.
- Нужно получить реальные данные через управляемый интерфейс 1С.
- Нужно сделать скриншот формы/документа/списка.
- Нужно диагностировать запуск `/TESTMANAGER`, `/TESTCLIENT`, `ibsrv` или автономный сервер.

## Базовый порядок

1. Проверь, что MCP-сервер `testclient-bridge` установлен и доступен.
2. Запусти инфраструктуру через MCP tool `launch_manager`.
3. Проверь `bridge_status` и `runtime_status`.
4. Подключи целевую базу через `connect_test_client`.
5. Работай только через tools testclient-bridge; не кликай X11 руками.
6. Скриншоты допускаются системно через `screenshot`.
7. При ошибках 1С выгружай журнал через `export_eventlog`.
8. В финальном ответе укажи реальные результаты: скриншоты, данные, ошибки, команды/формы.

## Важные правила

- `/TESTMANAGER` обязателен: не заменяй его обычным запуском 1С без явного указания пользователя.
- 1С-клиенты запускай с русской локалью: `/Lru /VLru_RU`.
- X11 использовать только для скриншотов, не для ввода/кликов/автоматизации.
- Для ссылочных полей предпочитай стандартную форму выбора 1С (`choose_field_from_list`, `choose_field_first_row`, `choose_current_row`), а не ввод строки.
- Для динамических списков `table_rows` может не сработать; используй выбор текущей строки, команды формы и скриншоты.
- Не заявляй выполнение UI-задачи без реального состояния/скриншота.

## Типовой запуск

```text
bridge_status()
launch_manager(platform_dir="/opt/1cv8/x86_64/8.5.1.1150")
bridge_status()
connect_test_client(
  base_url="<TARGET_INFOBASE_URL>",
  username="",
  password="",
  port=1538
)
active_window()
```

## Навигация

- Открывай формы/списки через `execute_window_command` с `e1cib/list/...` или `e1cib/app/...`, когда доступно.
- Для поиска объектов используй `find_object`, `activate_object`, `ui_tree`.
- Для команд формы используй `command_bar` и `execute_window_command`.

## Таблицы и табличные части

- `table_rows(table_name)` — получить строки, если объект поддерживает чтение.
- `table_find_row(table_name, substring)` — найти строку.
- `table_goto_row(table_name, index)` — перейти к строке.
- `table_set_field(table_name, field, value)` — установить значение ячейки.
- `table_edit_info(table_name)` — понять доступные поля редактирования.

## Диагностика

При сбоях запуска или непонятных ошибках:

```text
runtime_status()
export_eventlog(...)
```

Журнал автономного сервера — основной источник диагностики 1С runtime ошибок.
