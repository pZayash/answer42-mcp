# Справочник API

API Answer42 — это MCP-инструменты. Справочник собирается из реестра инструментов
сервера: описание — docstring инструмента, параметры — его JSON Schema, как их видит
MCP-клиент.

Инструменты разбиты на группы. Клиент всегда видит `core`; остальные подключаются
инструментом `tool_groups(action="enable", groups="...")`, параметром адреса HTTP-сервера
`?tools=...` или профилем сервера `--tool-profile`. Группа `html` включается сама после
`start_session`, `ui_snapshots` — когда `ui_tree` сохранил результат в ресурс, `rag` видна
только пока RAG активен. Подробнее — в разделе «Группы инструментов» {doc}`../guides/overview`.

Почти все инструменты принимают `session_id`: в stdio без него используется сессия
`default`, в HTTP-режиме он обязателен (его возвращает `start_session`).
